This illustrated newspaper front page places six headlines around a central globe under a Wednesday, 25 November 2026 dateline. The panels cover the U.S. House, strikes near Kyiv, a missile hit in Riyadh, Huawei’s trade secrets verdict, Nvidia’s stock rally, and a graft investigation in Shanghai. Run `python3 main.py` to copy the bundled image to `/output/entry.png`, or run `MAKEFUN_OUTPUT_DIR=./out python3 main.py` to write it to `./out/entry.png`.
